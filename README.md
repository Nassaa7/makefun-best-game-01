Emberwild is an original arena-survival game: play Luma, the last lanternkeeper, defending a glowing night garden through 10 waves of gloom creatures, choosing boons on every level-up, and felling the Hollow Moth boss. It runs entirely offline from static files, with synthesised sound, a full start–pause–upgrade–victory/defeat loop, and an endless mode after victory.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Keyboard and mouse: WASD to move, mouse to aim, hold click to shoot, Space to dash, E for a nova blast, P to pause.
